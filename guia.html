Para el profe

Cómo agregar contenido

Todo el sitio se ordena desde un solo archivo: assets/js/contenido.js. Los ejercicios van en archivos HTML dentro de contenido/. No hay que instalar nada ni compilar: se sube a GitHub y listo.

Cada alumno entra por su propio enlace y solo ve sus temas. Este panel y esta guía están protegidos con una clave y no se enlazan desde ninguna página de alumno.

0

La regla es simple: un alumno es una carpeta, un tema es una subcarpeta y cada nivel es un archivo llamado basico.html, intermedio.html o avanzado.html.

1

Agregar un alumno

En el panel, usa Generar código: te da un código como k7m2p9x4 y el bloque listo para copiar. Luego pégalo dentro de alumnos, en assets/js/contenido.js: 

{
  id: "k7m2p9x4",              // el código: no lleva el nombre del alumno
  nombre: "Carla Mendoza",
  curso: "3.º de secundaria",  // opcional
  nota: "Números enteros",     // opcional
  temas: []                    // se llena en el paso 2
}

Ese código es también el nombre de su carpeta en contenido/ y la parte del enlace que ven los alumnos, así que no contiene su nombre.

2

Agregar un tema

  1. Crea la carpeta contenido/k7m2p9x4/enteros/.
  2. Copia plantillas/seccion.html tres veces dentro de ella y renombra las copias como basico.html, intermedio.html y avanzado.html.
  3. En cada copia cambia el data-seccion del <body> y el <title>. Por ejemplo: data-seccion="k7m2p9x4/enteros/basico".
  4. Agrega el tema en el alumno, dentro de temas:
{ id: "enteros", titulo: "Números enteros" }

Si el tema todavía no tiene los tres niveles, se indica cuáles existen: 

{ id: "enteros", titulo: "Números enteros", niveles: ["basico", "intermedio"] }
3

Agregar un ejercicio

Abre el archivo del nivel que corresponda y pega un bloque como este dentro de <ol class="ejercicios">. La numeración es automática. 

<li class="ejercicio">
  <p class="enunciado">Calcula \(\frac{1}{2}+\frac{1}{3}\).</p>

  <details class="solucion">
    <summary>Ver solución</summary>
    <div class="pasos">
      <p>Se busca el denominador común \(6\):</p>
      <p>\(\frac{3}{6}+\frac{2}{6}=\frac{5}{6}\).</p>
      <p class="respuesta">\(\frac{5}{6}\)</p>
    </div>
  </details>
</li>

Si quieres separar los ejercicios por tipo, envuelve cada grupo en un <section class="bloque"> con su <h2> (así están organizadas las secciones de ejemplo).

También puedes agregar una pista antes de la solución: 

<details class="pista">
  <summary>Ver pista</summary>
  <p>Recuerda que \(\frac{1}{2}=\frac{3}{6}\).</p>
</details>
4

Escribir el solucionario con KaTeX

Las fórmulas se escriben entre \( y \) si van dentro de una frase, o entre $$ y $$ si van centradas en su propio renglón. KaTeX se encarga del resto; las soluciones quedan ocultas hasta que el alumno hace clic. 

Dentro de una frase: \(\frac{a}{b}\) y también \(x^2+1\).

En su propio renglón:
$$ x=\frac{-b\pm\sqrt{b^2-4ac}}{2a} $$
Quiero escribirSe escribe
Fracción\frac{3}{4}
Raíz cuadrada\sqrt{x} o \sqrt[3]{x}
Potencia y subíndicex^{2} y a_{n}
Multiplicación y división\cdot y \div
Menor o igual, distinto\le y \neq
Paréntesis que crecen\left( \frac{1}{2} \right)
Infinito, pi, alfa\infty, \pi, \alpha
Texto dentro de una fórmula\text{si } x\neq 0
Sistema de ecuaciones\begin{cases} x+y=5 \\ x-y=1 \end{cases}

Ojo con dos cosas: si escribes < o > dentro del HTML, cámbialos por &lt; y &gt;. Y en un sistema de ecuaciones cada salto de línea se escribe con \\.

5

Compartir el enlace con cada alumno

  1. Entra a index.html y escribe la clave del panel.
  2. Cada tarjeta muestra el enlace del alumno y un botón Copiar enlace.
  3. Envía ese enlace. El alumno verá solo sus temas: no hay botones hacia el panel ni hacia sus compañeros.

El enlace tiene esta forma:

https://tu-usuario.github.io/web-math-exercises/alumno.html?alumno=k7m2p9x4

La clave está en assets/js/clave.js y se puede cambiar desde el panel (sección «Cambiar la clave»). Evita reutilizar una clave que uses en otro sitio.

Esto es una cortina, no una cerradura.

GitHub Pages es público: quien tenga la dirección de un archivo puede abrirlo, y quien sepa mirar el código puede ver la lista de alumnos y las rutas. Lo que sí logras es que un alumno no se tope con los demás ni con el panel. Para privacidad real, mira el último paso.

6

Activar o desactivar soluciones

En el panel, abre Solucionarios. Elige un alumno, abre una sección y verás cada ejercicio con su casilla: si la desmarcas, ese ejercicio se queda sin solución para los alumnos (el resto no cambia).

  1. Haz los cambios que quieras (también puedes usar «Activar todas» o «Desactivar todas»).
  2. Pulsa Descargar soluciones.js (o «Copiar contenido»).
  3. Reemplaza con ese archivo assets/js/soluciones.js y sube el cambio.

El panel reconoce cada ejercicio por su enunciado: si cambias el texto de un enunciado, ese interruptor vuelve a «mostrar». Las páginas vuelven a leer soluciones.js al cargarse, así que los alumnos no necesitan borrar la caché ni reabrir el navegador: en la siguiente visita el cambio ya está aplicado.

Los interruptores necesitan un servidor.

Si abres el panel con doble clic (file://) no puede leer los archivos de ejercicios. Ábrelo desde GitHub Pages o con node herramientas/servidor.mjs, que sirve el sitio sin caché.

7

Revisar y publicar

  • Antes de subir los cambios, en la carpeta del proyecto ejecuta node herramientas/verificar.mjs: te avisa si falta un archivo, si un data-seccion no coincide o si hay un id repetido.
  • Sube los cambios a GitHub: git add ., git commit -m "nuevo tema" y git push.
  • En GitHub, entra a Settings → Pages, elige la rama main y la carpeta / (root). El sitio queda publicado en https://tu-usuario.github.io/web-math-exercises/.
  • Para verlo en tu computadora puedes abrir index.html con doble clic (te pedirá la clave) o, mejor, ejecutar node herramientas/servidor.mjs: sirve el sitio sin caché en http://127.0.0.1:8765/.
8

Si necesitas privacidad de verdad

En GitHub Pages no se puede. Cualquier archivo del sitio es público y la clave del panel se puede saltar mirando el código. Alternativas reales:

  • Cloudflare Access delante del sitio: el alumno inicia sesión con un código que llega a su correo. Tiene plan gratuito para equipos pequeños y no hay que tocar el código del cuaderno.
  • Un hosting con contraseña (por ejemplo Netlify, en sus planes pagos).
  • Páginas cifradas antes de publicarlas (por ejemplo PageCrypt): sin la clave el archivo no se puede leer ni mirando el código.
  • Repositorio privado: oculta el código en GitHub, pero el sitio de Pages sigue siendo público; además, Pages desde un repositorio privado requiere un plan de pago.

Si quieres, puedo ayudarte a montar la opción que elijas.

Los contenidos de ejemplo (Ana y Beto) se pueden borrar sin miedo: elimina sus bloques en contenido.js y sus carpetas en contenido/.
